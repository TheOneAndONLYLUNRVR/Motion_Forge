FX LIBRARY

Your After Effects, organized

Every effect here is applied with After Effects' own native engine — nothing bundled, nothing that can go stale. The Third-Party category only shows plugins actually detected as installed on this computer (e.g. Twixtor, Trapcode) — if it's not installed, it simply won't appear.

TEXT COMPOSER

Add a text layer

3D layers can be positioned, rotated and lit in space. Real per-character extrusion additionally needs the Cinema 4D renderer — Motion Forge turns that on automatically when your After Effects install supports it, and still applies the 3D transform safely if it doesn't. After creating a layer, press Set as Destination, then use the Camera tab's Rig Jump to snap your camera rig onto it.

POWER TOOLS

Run your own script

Runs as real ExtendScript against your project. Available to your code: comp (active composition), layers (array of selected layers), layer (first selected layer, or null), project (app.project), plus the full After Effects app object. Wrapped in one undo step.
POWER TOOLS

Image → animated template

Imports your image, fits it to the comp, and (if checked) adds a real, editable text layer on top — parented to the image, so moving/scaling/animating the image moves the text with it. Double-click the text layer afterward to type whatever you want; it's not baked into the image. The crop mask adds ready-to-drag handles just inside the image's edges — After Effects has no content-aware "isolate this one square" detection, so this gives you a starting mask to adjust rather than drawing one from scratch.
POWER TOOLS

Attach audio to selected clips

Select the clips you want it on (Shift-click each one in the timeline), then press below. You'll be asked to pick the audio file once, and it's added aligned to the start of every selected clip.

CAMERA RIG JUMP

Snap your camera rig to a layer

Rig Null — the Null your camera is parented to
Destination — text, image or any layer
Select a layer, press Set Slot 1 (your Null), select another, press Set Slot 2, then Jump. The Null copies the destination's position (and orientation for 3D layers); the camera follows because it's parented to it.
